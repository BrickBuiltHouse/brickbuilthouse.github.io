Wprowadzenie do przedmiotu, PSO i środowisko pracy

1 godzina · Organizacja nauki i przygotowanie komputera do tworzenia aplikacji

1. Czym zajmuje się Programowanie Aplikacji Internetowych?

Przedmiot dotyczy tworzenia aplikacji działających w sieci. W pierwszej części kursu poznajemy PHP, czyli język wykonywany po stronie serwera. Następnie przechodzimy do JavaScript, który działa w przeglądarce użytkownika.

Przeglądarka→ żądanie HTTP →Serwer (PHP)→ odpowiedź HTML/JSON →Przeglądarka

Przykładowo: użytkownik otwiera stronę z listą uczniów. Serwer może pobrać rekordy z MySQL przy użyciu PHP, wygenerować HTML i odesłać go do przeglądarki. JavaScript może następnie obsługiwać zdarzenia i aktualizować elementy strony.

2. Przedmiotowy System Oceniania (PSO)

PSO określa, jakie umiejętności i aktywności podlegają ocenie, jakie są kryteria oraz jak można poprawiać wyniki. Poniższy układ pochodzi z materiału lekcyjnego i jest przykładowy — wiążące są zasady zatwierdzone w danej szkole.

4. XAMPP — lokalne środowisko serwerowe

Serwer lokalnyTo środowisko uruchomione na własnym komputerze, które pozwala testować aplikację webową bez publikowania jej w Internecie. Adres localhost wskazuje na komputer, z którego korzystamy.

XAMPP to pakiet zawierający m.in. serwer Apache, interpreter PHP i serwer bazodanowy MySQL/MariaDB. Dzięki niemu można lokalnie testować skrypty PHP oraz aplikacje korzystające z bazy danych.

Instalacja i pierwszy test

  1. Pobierz instalator XAMPP z oficjalnej strony apachefriends.org.
  2. Zainstaluj pakiet i uruchom XAMPP Control Panel.
  3. Uruchom moduły Apache i — gdy potrzebujesz bazy danych — MySQL.
  4. Umieszczaj pliki projektu w katalogu dokumentów serwera: C:\xampp\htdocs\ w typowej instalacji Windows albo /opt/lampp/htdocs/ w typowej instalacji Linux.
  5. Utwórz katalog test, a w nim plik index.php.
  6. Otwórz w przeglądarce adres http://localhost/test/.
index.phpPHP · pierwszy test
<?php
echo "Działa!";
?>

Jeśli wszystko jest poprawnie skonfigurowane, przeglądarka wyświetli tekst „Działa!”. Nie otwieramy takiego pliku dwukrotnym kliknięciem z dysku — musi zostać obsłużony przez serwer PHP.

Panel phpMyAdmin jest zwykle dostępny pod adresem http://localhost/phpmyadmin/. Służy do zarządzania bazami danych i będzie wykorzystywany w dalszej części kursu.

Zapamiętajhtdocs to katalog projektów, Apache obsługuje żądania HTTP, PHP wykonuje kod serwerowy, a phpMyAdmin ułatwia zarządzanie bazą danych.

1. Struktura skryptu PHP

PHP zapisujemy zwykle w plikach z rozszerzeniem .php. Kod przeznaczony do wykonania przez interpreter umieszczamy między znacznikami <?php i ?>. Plik powinien znajdować się w katalogu obsługiwanym przez serwer, np. htdocs.

2. Zmienne

ZmiennaNazwana komórka danych, której wartość może być odczytywana i — w razie potrzeby — zmieniana w trakcie działania programu.

W PHP nazwa zmiennej rozpoczyna się od znaku $. Język jest dynamicznie typowany: typ wartości jest rozpoznawany w czasie działania i nie trzeba go zwykle deklarować przy tworzeniu zmiennej.

zmienne.phpPHP · przykładowe wartości
<?php
$imie = "Anna";       // string — tekst
$wiek = 17;           // integer — liczba całkowita
$srednia = 4.5;       // float — liczba zmiennoprzecinkowa
$uczen = true;        // boolean — prawda/fałsz

$wiek = 18;           // zmiana wartości zmiennej
?>

Poprawna nazwa zmiennej zaczyna się od litery lub podkreślenia, a później może zawierać litery, cyfry i podkreślenia. Wielkość liter ma znaczenie: $imie i $Imie to różne zmienne.

3. Stałe

StałaNazwa przypisana do wartości, której nie zmieniamy w trakcie działania programu. W przeciwieństwie do zmiennej jej nazwy nie poprzedzamy znakiem $.
stale.phpPHP · define() i const
<?php
define("SZKOLA", "Technikum nr 1");
const WERSJA = "1.0";

echo SZKOLA;
echo WERSJA;
?>

define() tworzy stałą w czasie wykonywania programu. const deklaruje stałą w składni języka. W prostych przykładach obie formy służą do przechowywania wartości, które mają pozostać niezmienne.

Obsługa parametrów GET

3 godziny · Dane przekazywane w adresie URL

1. Query string — parametry w adresie URL

Query stringCzęść adresu URL rozpoczynająca się od znaku ?. Zawiera pary klucz–wartość. Kolejne parametry oddzielamy znakiem &.
Przykładowy adresGET · query string
http://localhost/PAI_kurs/blok03_get/przyklad.php?imie=Anna&wiek=17

W przykładzie przekazano dwa parametry: imie o wartości Anna i wiek o wartości 17.

2. Superglobalna tablica $_GET

PHP udostępnia parametry GET w tablicy superglobalnej $_GET. Jest ona dostępna w różnych zakresach skryptu bez przekazywania jej jako argumentu funkcji.

odczyt_get.phpPHP · prosty odczyt
<?php
$imie = $_GET['imie']; // np. "Anna"
$wiek = $_GET['wiek']; // np. "17"
echo "Cześć, $imie!";
?>
Brak parametruBezpośredni odczyt $_GET['imie'] może wywołać ostrzeżenie, jeśli użytkownik otworzy stronę bez parametru imie. Dane wejściowe należy sprawdzać przed użyciem. Typowe proste wartości parametrów GET są odczytywane jako tekst; kształt nazwy z nawiasami kwadratowymi może utworzyć tablicę.

3. Bezpieczne sprawdzanie, czy parametr istnieje

Do najczęściej stosowanych rozwiązań należą isset(), empty() i operator null coalescing ??.

sprawdzanie_get.phpPHP · isset() i ??
<?php
// Wariant 1 — warunek
if (isset($_GET['imie'])) {
    $imie = $_GET['imie'];
} else {
    $imie = "Gość";
}

// Wariant 2 — krótszy zapis
$imie = $_GET['imie'] ?? "Gość";
?>
MechanizmCo sprawdza?Ważna uwaga
isset($x)Czy zmienna/element istnieje i nie ma wartości null.Wartość "" i 0 nadal może być ustawiona.
empty($x)Czy wartość jest „pusta” według reguł PHP.Za pustą uznaje m.in. "0", 0, false, pusty tekst, pustą tablicę i brak zmiennej.
$x ?? $domyslnaZwraca wartość z lewej strony, jeśli istnieje i nie jest null; w przeciwnym razie wartość domyślną.Wygodny sposób na obsługę braku parametru.

4. Formularz wysyłający dane metodą GET

formularz_get.htmlHTML · metoda GET

    <label>

5. Wyświetlanie danych użytkownika i XSS

XSS (Cross-Site Scripting)Rodzaj ataku polegający na doprowadzeniu do wykonania niepożądanego kodu po stronie przeglądarki, np. przez wstawienie złośliwego znacznika lub skryptu do treści wyświetlanej na stronie.

Dane pochodzące od użytkownika należy odpowiednio kodować przy umieszczaniu ich w HTML. W PHP służy do tego m.in. htmlspecialchars().

bezpieczne_wyswietlanie.phpPHP · kodowanie tekstu HTML
<?php
$imie = $_GET['imie'] ?? '';
echo "Witaj, " . htmlspecialchars($imie, ENT_QUOTES, 'UTF-8');
?>
Walidacja to nie to samo co kodowanieWalidacja sprawdza, czy dane spełniają wymagania (np. czy wiek jest liczbą). htmlspecialchars() zabezpiecza sposób umieszczenia tekstu w HTML. Jedno nie zastępuje drugiego.

6. Typowe zastosowania GET

  • Przechodzenie do konkretnej strony listy: lista.php?strona=2.
  • Filtrowanie produktów: sklep.php?kategoria=buty&sort=cena.
  • Wskazywanie rekordu: produkt.php?id=15.
  • Wyszukiwanie: wyniki.php?fraza=php.
ZapamiętajGET służy typowo do odczytu i filtrowania danych. Parametry są widoczne w URL, mogą zostać skopiowane i zapisane w zakładce. Nigdy nie umieszczaj w adresie poufnych informacji, np. haseł.

Instrukcje warunkowe i pętle w PHP

3 godziny · Sterowanie przebiegiem programu

1. Instrukcja if / elseif / else

Instrukcja warunkowa pozwala wykonać różne fragmenty kodu zależnie od tego, czy warunek jest prawdziwy.

warunki.phpPHP · dobór oceny
<?php
$ocena = 4;

if ($ocena >= 5) {
    echo "Bardzo dobry";
} elseif ($ocena >= 4) {
    echo "Dobry";
} elseif ($ocena >= 3) {
    echo "Dostateczny";
} else {
    echo "Niedostateczny";
}
?>

Warunki są sprawdzane od góry. Wykonany zostaje pierwszy blok, którego warunek jest prawdziwy. Jeżeli żaden nie pasuje, wykonywany jest blok else, jeśli został podany.

2. Instrukcja switch

switch jest wygodny, gdy jedna zmienna może przyjmować kilka konkretnych wartości.

switch.phpPHP · wybór dnia
<?php
$dzien = 3;

switch ($dzien) {
    case 1:
        echo "Poniedziałek";
        break;
    case 2:
        echo "Wtorek";
        break;
    case 3:
        echo "Środa";
        break;
    default:
        echo "Nieznany dzień";
}
?>

break kończy wykonywanie danej gałęzi. Bez niego program może przejść do kolejnego case (zjawisko fall-through).

3. Pętla for

Pętla for jest wygodna, gdy znamy liczbę iteracji lub chcemy kontrolować licznik.

for.phpPHP · pięć iteracji
<?php
for ($i = 1; $i <= 5; $i++) {
    echo "Iteracja $i<br>";
}
?>

Trzy części nagłówka pętli oznaczają: inicjalizację licznika ($i = 1), warunek kontynuacji ($i <= 5) i zmianę licznika po każdej iteracji ($i++).

4. Pętle while i do...while

while sprawdza warunek przed wykonaniem treści. do...while najpierw wykonuje treść, a dopiero później sprawdza warunek — dlatego wykona się przynajmniej raz.

while.phpPHP · warunek przed wykonaniem
<?php
$i = 1;
while ($i <= 5) {
    echo $i . " ";
    $i++;
}
?>
do_while.phpPHP · wykonanie przed sprawdzeniem
<?php
$i = 1;
do {
    echo $i . " ";
    $i++;
} while ($i <= 5);
?>
Pułapka pętliW pętli while pamiętaj o zmianie wartości wpływającej na warunek. Jeśli warunek nigdy nie stanie się fałszywy, powstanie pętla nieskończona.

5. Pętla foreach — przechodzenie po tablicy

foreach przechodzi po kolejnych elementach tablicy bez ręcznego zarządzania indeksem.

foreach.phpPHP · wartości tablicy
<?php
$owoce = ["jabłko", "gruszka", "banan"];

foreach ($owoce as $owoc) {
    echo $owoc . "<br>";
}
?>

W tablicy asocjacyjnej można pobierać jednocześnie klucz i wartość:

foreach_klucz_wartosc.phpPHP · klucz i wartość
<?php
$uczen = ["imie" => "Anna", "klasa" => "3TI"];

foreach ($uczen as $klucz => $wartosc) {
    echo "$klucz: $wartosc<br>";
}
?>

6. break i continue

  • break natychmiast kończy bieżącą pętlę lub instrukcję switch.
  • continue pomija pozostałą część bieżącej iteracji i przechodzi do następnej.
break_continue.phpPHP · przerywanie i pomijanie iteracji
<?php
for ($i = 1; $i <= 10; $i++) {
    if ($i == 5) {
        break;       // pętla kończy się przy i = 5
    }
    if ($i % 2 == 0) {
        continue;    // pomiń liczby parzyste
    }
    echo $i . " ";
}
// Wynik: 1 3
?>
Do zapamiętaniafor — licznik i znana liczba powtórzeń; while — warunek przed iteracją; do...while — treść co najmniej raz; foreach — elementy tablicy; break — zakończ; continue — pomiń tę iterację.

3 godziny · Przechowywanie i przetwarzanie wielu wartości

1. Czym jest tablica?

Tablica (array)Struktura danych, która przechowuje wiele wartości pod wspólną nazwą. Do elementów odwołujemy się za pomocą indeksów lub kluczy.

Walidacja HTML5 (np. required, min, max) poprawia wygodę użytkownika, ale można ją ominąć. Ostateczną kontrolę trzeba wykonać na serwerze.

1. Prosty zapis i odczyt plików

zapis_odczyt.phpPHP · file_put_contents i file_get_contents

);

Informacje o pliku trafiają do superglobalnej tablicy $_FILES. W typowym procesie PHP sprawdzamy status uploadu, nazwę, rozszerzenie i przenosimy plik z lokalizacji tymczasowej do docelowej.

upload.phpPHP · uproszczony schemat uploadu
<?php
if (
    isset($_FILES['plik']) &&
    $_FILES['plik']['error'] === UPLOAD_ERR_OK
) {

        } else {
            echo "Nie udało się zapisać pliku";
        }
    } else {
        echo "Niedozwolony typ pliku!";
    }
}
?>

Sesje i ciasteczka w PHP

3 godziny · Zapamiętywanie informacji pomiędzy żądaniami HTTP

1. Problem bezstanowości HTTP

Bezstanowość HTTPKażde żądanie HTTP jest niezależne. Serwer nie pamięta automatycznie, co użytkownik zrobił w poprzednim żądaniu. Aby zachować informacje między odwiedzinami stron, aplikacja korzysta m.in. z sesji i ciasteczek.

Przykład: użytkownik loguje się na stronie. Po przejściu z formularza logowania do panelu serwer musi rozpoznać, że kolejne żądanie pochodzi od zalogowanego użytkownika. Służy do tego identyfikator sesji.

2. Sesje — $_SESSION

Sesja przechowuje dane po stronie serwera. Przeglądarka otrzymuje identyfikator sesji, zwykle zapisywany w ciasteczku o nazwie PHPSESSID. Przy kolejnym żądaniu przeglądarka odsyła identyfikator, a PHP odnajduje odpowiadające mu dane.

sesja.phpPHP · uruchomienie i zapis danych sesji
<?php
session_start(); // przed jakimkolwiek HTML lub echo

$_SESSION['imie'] = "Anna";
$_SESSION['licznik'] = ($_SESSION['licznik'] ?? 0) + 1;

echo "Witaj, " . htmlspecialchars($_SESSION['imie'], ENT_QUOTES, 'UTF-8');
echo "! Odwiedziłeś stronę ";
echo (int)$_SESSION['licznik'];
echo " razy.";
?>
session_start() przed wyjściemsession_start() powinno zostać wywołane przed wysłaniem jakiejkolwiek treści do przeglądarki. W przeciwnym razie PHP może nie móc wysłać nagłówków związanych z sesją.

3. Usuwanie danych i kończenie sesji

koniec_sesji.phpPHP · różne poziomy usuwania
<?php
session_start();

unset($_SESSION['imie']); // usuń jedną wartość
session_unset();           // usuń wszystkie zmienne sesji
session_destroy();         // zakończ sesję po stronie serwera
?>

unset() usuwa wskazany element. session_unset() usuwa zmienne sesji, a session_destroy() niszczy dane bieżącej sesji po stronie serwera. Samo session_destroy() nie usuwa automatycznie ciasteczka identyfikatora z przeglądarki.

4. Ciasteczka — setcookie() i $_COOKIE

Cookie (ciasteczko)Niewielka porcja danych zapisywana przez przeglądarkę dla określonej witryny. Jest automatycznie dołączana do kolejnych żądań, zgodnie z ustawionym zakresem i terminem ważności.
cookie.phpPHP · ustawianie, odczyt i usuwanie
<?php
// Ustawienie ciasteczka na 30 dni — przed wysłaniem treści strony.
setcookie("jezyk", "pl", time() + 3600 * 24 * 30, "/");

// Wartość jest dostępna z żądania, które zawiera cookie.
$jezyk = $_COOKIE['jezyk'] ?? 'nieznany';
echo "Wybrany język: " . htmlspecialchars($jezyk, ENT_QUOTES, 'UTF-8');

// Usunięcie: ustawienie daty wygaśnięcia w przeszłości.
setcookie("jezyk", "", time() - 3600, "/");
?>

Nowo ustawione ciasteczko jest zwykle dostępne w $_COOKIE dopiero przy kolejnym żądaniu, ponieważ przeglądarka musi najpierw otrzymać nagłówek Set-Cookie, zapisać cookie, a potem odesłać je z powrotem.

4. Funkcja zwracająca obiekt — statystyki

Funkcja może zwrócić obiekt z kilkoma obliczonymi wartościami. W przykładzie wykorzystywane są metody tablicy reduce(), Math.max() i Math.min().

statystyki.jsJavaScript · obliczanie statystyk
function statystyki(liczby) {
    if (liczby.length === 0) {
        return null;
    }

    const suma = liczby.reduce((a, b) => a + b, 0);

    return {
        suma: suma,
        srednia: suma / liczby.length,
        max: Math.max(...liczby),
        min: Math.min(...liczby)
    };
}

console.log(statystyki([3, 7, 2, 9]));

reduce() przechodzi przez tablicę i sprowadza jej elementy do jednej wartości. W tym przykładzie oblicza sumę. Operator ... (spread) przekazuje elementy tablicy jako osobne argumenty do Math.max() i Math.min().

1. Najważniejsze zagadnienia — checklista

  • Wiem, czym różni się kod wykonywany po stronie serwera od kodu wykonywanego w przeglądarce.
  • Potrafię uruchomić projekt PHP przez Apache w XAMPP i wiem, gdzie znajduje się katalog htdocs.
  • Rozpoznaję zmienne, stałe, typy danych i operatory PHP.
  • Odczytuję parametry z $_GET i dane formularza z $_POST.
  • Potrafię sprawdzić dane wejściowe, zwalidować je i bezpiecznie wyświetlić przez htmlspecialchars().
  • Umiem stosować instrukcje warunkowe, pętle i tablice.
  • Potrafię zdefiniować funkcję, zwrócić wynik i dołączyć inny plik PHP.
  • Rozumiem różnicę pomiędzy SELECT, INSERT, UPDATE i DELETE.
  • Stosuję prepared statements, aby nie łączyć danych użytkownika bezpośrednio z SQL.
  • Umiem zapisać i odczytać plik oraz wyjaśnić, jak działa upload.
  • Rozumiem serializację JSON i różnicę pomiędzy JSON a serialize().
  • Wyjaśniam, gdzie przechowywane są dane sesji i ciasteczka.
  • W JavaScript znam let, const, typy, operatory, warunki, pętle i funkcje.
  • Potrafię utworzyć obiekt, klasę, instancję i wyjaśnić działanie this.

5. Uzupełnienia i korekty merytoryczne

W kilku miejscach materiał lekcyjny używa skrótów myślowych, które są przydatne na początku nauki, ale wymagają doprecyzowania:

  • Limit GET: nie istnieje jeden uniwersalny limit „około 2000 znaków” dla wszystkich środowisk. Długość URL ograniczają konkretne przeglądarki, serwery i elementy infrastruktury.
  • POST: dane nie pojawiają się w pasku adresu, ale POST nie zapewnia szyfrowania ani poufności. Do tego służy HTTPS.
  • Typ danych GET/POST: proste wartości parametrów są zwykle tekstem, ale formularze mogą przekazywać również tablice (np. przez nazwy zakończone []).
  • Tekst UTF-8: strlen() mierzy bajty, a nie znaki; dla polskich znaków używaj funkcji mb_*.
  • Sesje: domyślne zachowanie czasu życia sesji zależy od konfiguracji. Samo zamknięcie przeglądarki nie jest uniwersalną gwarancją natychmiastowego usunięcia danych sesji z serwera.
  • Upload: lista dozwolonych rozszerzeń nie wystarcza. Należy weryfikować typ pliku i jego rozmiar oraz bezpiecznie przechowywać pliki.
  • Hasła: przykład logowania z hasłem zapisanym w kodzie jest wyłącznie demonstracją. W praktyce hasła przechowuje się jako bezpieczne skróty.
  • Usuwanie danych: operacje zmieniające stan aplikacji (np. usuwanie rekordu) powinny być chronione i nie powinny być uruchamiane przez zwykły link GET.
